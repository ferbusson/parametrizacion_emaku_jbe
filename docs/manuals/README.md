Each manual follows this structure:
- **Overview**: Purpose and scope
- **Prerequisites**: Required permissions and setup
- **Step-by-Step Procedures**: Detailed instructions with screenshots
- **Field Reference**: Description of all form fields
- **Common Scenarios**: Real-world use cases
- **Troubleshooting**: Common issues and solutions
