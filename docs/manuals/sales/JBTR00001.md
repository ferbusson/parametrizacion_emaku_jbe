### What It Does
El formulario de Pedidos permite registrar los productos que un cliente desea llevar, solicita el nombre o número de identificación del cliente (el cliente ya debe estar creado con anterioridad a travez de la opción que se encuentra en el menú Terceros-Nuevo Tercero Cajas), el cliente por defecto es Clientes Varios Nit 222222222222 que esta definido por la DIAN como tercero cuando el cliente no da esta información, la tabla de productos en donde se puede digitar directamente el codigo del producto o se puede buscar presionando la tecla F2 para que salga el cuadro en donde se puede especificar el nombre o parte de la descripción del producto, al hacer esto se da Enter y el sistema va a listar las opciones coincidentes, con el mouse o usando la flecha Abajo del teclado se puede expandir la lista de opciones coincidentes con la búsqueda para luego seleccionar la deseada, repitiendo la acción anterior se continua hasta tener el listado completo de productos que el cliente desea llevar. Esta es la información básica para realizar un pedido, se puede proceder a hacer clic en el botón Guardar, con esto el sistema da la opción de Imprimir en físico (Hoja Carta) el pedido, adicionalmente y el sistema mostrará el número de pedido generado con el cual el cliente puede pasar a Facturación.
